# Lab 01: Basics & First EC2 Instance

This lab demonstrates how to configure the AWS provider and provision your first EC2 instance with Terraform.

## Prerequisites
- AWS CLI configured or environment variables set (`AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_REGION`).

## Usage

```bash
# Initialize Terraform
terraform init

# Review execution plan
terraform plan

# Apply changes
terraform apply
```
